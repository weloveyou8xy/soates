# Soates | https://soates.org

**The music player built for developers.**
YouTube audio streaming — no video, no clutter, no compromise.

Published by the House of Heroia · developed by 8xy

## Download

Grab the latest installer from the
[**Releases**](https://github.com/weloveyou8xy/soates/releases/latest) page →
run `Soates-Setup-x.x.x.exe`.

> Windows SmartScreen may warn on first launch (unsigned beta build):
> click **More info → Run anyway**.

The app updates itself automatically — install once, stay current.
